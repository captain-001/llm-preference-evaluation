# Results

The CSV files in this directory contain compact summary tables
transcribed from the current experiment report and notebook outputs.

The full notebook exports additional per-sample predictions,
method-level results, split metadata, statistical outputs, ablation
predictions and plots to `task2_results/` when run. That runtime export
is not duplicated here.

Treat these CSVs as a snapshot of the recorded run, not as results from
a fresh run. A rerun may differ because of API/model updates or service
conditions.
