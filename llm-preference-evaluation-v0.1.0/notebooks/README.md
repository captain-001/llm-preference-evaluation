# Notebooks

- `01_preference_evaluation.ipynb` is the canonical notebook for this
  release. It contains the improved experimental workflow and saved
  execution outputs.
- `archive/00_original_coursework.ipynb` preserves the initial
  coursework notebook.

  intermediate randomized-order version.

Use the canonical notebook for the current reported results. The
archived notebooks are retained for development history and should not
be treated as the final experimental implementation.
