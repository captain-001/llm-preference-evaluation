# Reports

`preference_evaluation_report.tex` is the LaTeX source for the current
experiment report. The author field has been changed to a project-level
label for public sharing; student identifiers are not included.

To build the PDF locally, use a LaTeX distribution with the packages
referenced in the source:

``` bash
pdflatex preference_evaluation_report.tex
pdflatex preference_evaluation_report.tex
```

The report source uses a manually written bibliography. Generated PDF
and auxiliary build files are not included in this initial repository
snapshot.
